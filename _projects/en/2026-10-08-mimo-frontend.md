A local game library with a console-inspired interface and a dedicated website presenting the project.

MIMO-FE brings together interface design and desktop application development with React, TypeScript, Vite and Tauri. The documented beta includes keyboard and controller navigation, a configurable library, data stored in SQLite and an optional XML manifest for portability.

The project also includes a Next.js website bringing together updates, documentation, support and access to releases. Its visual identity uses four colours, an interactive theme selector and layouts that adapt to different screens.

The application is a desktop beta. Its README distinguishes local validation on macOS Apple Silicon from packages prepared for other platforms.

## Technologies

React, TypeScript, Vite, Tauri, Rust, SQLite, Next.js.
