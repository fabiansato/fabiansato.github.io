A command-line tool for auditing multiple URLs and collecting PageSpeed Insights results in CSV reports.

The public repository documents batch audits of performance, accessibility, SEO and best practices, with mobile and desktop analysis. Reports bring results from multiple pages together in a file for review.

The published workflow uses a URL list and terminal execution. A web interface is described as a future possibility; this entry presents the available CLI tool.

## Technologies

JavaScript, Node.js, PageSpeed Insights, Lighthouse, CSV.
