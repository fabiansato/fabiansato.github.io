A store project for games, technology and collectibles, with a Tiendanube theme and catalogue tools.

The repository organises Kit Maestro’s work on the Ipanema theme: layouts, configurable sections, blocks, shared components, styles and translations. Store design and catalogue data have separate structures so each part can evolve independently.

Alongside the theme, the code includes scripts for catalogue validation, planning and synchronisation, plus a structure for OAuth and webhook integrations. The documented workflow tests changes in a development environment before considering publication.

A public lab for commerce implementation and tooling, presented through its source code and documentation.

## Technologies

Tiendanube, Templates, JavaScript, CSS, Node.js, JSON.
