A React and TypeScript store project with a catalogue, shopping cart and administration structure.

The public code includes product views, a cart with add, remove and clear operations, authentication routes and administration screens for products, categories and design. Dependencies include Firebase, React Router and Bootstrap.

A public lab exploring commerce interfaces, shared state management and React application structure. The source code is available to inspect the implementation and continue development.

## Technologies

React, TypeScript, Firebase, React Router, Bootstrap.
