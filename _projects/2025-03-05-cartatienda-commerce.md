Proyecto de tienda en React y TypeScript con catálogo, carrito y estructura de administración.

El código público incluye vistas de productos, un carrito con operaciones de agregar, quitar y vaciar, rutas de autenticación y pantallas de administración de productos, categorías y diseño. Las dependencias incluyen Firebase, React Router y Bootstrap.

Un laboratorio público para explorar interfaces de comercio, manejo de estado compartido y organización de una aplicación React. El código permite recorrer la implementación y continuar el desarrollo.

## Tecnologías

React, TypeScript, Firebase, React Router, Bootstrap.
