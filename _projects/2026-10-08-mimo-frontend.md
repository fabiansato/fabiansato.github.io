Una biblioteca de juegos local con una interfaz inspirada en consolas y un sitio web propio para presentar el proyecto.

MIMO-FE reúne diseño de interfaz y desarrollo de una aplicación de escritorio con React, TypeScript, Vite y Tauri. La beta documenta navegación con teclado y controles, una biblioteca configurable, datos guardados en SQLite y un manifiesto XML opcional para portabilidad.

El proyecto también incluye una web en Next.js que concentra novedades, documentación, soporte y acceso a versiones. Su identidad visual se apoya en cuatro colores, un selector interactivo de tema y una composición adaptable a distintas pantallas.

La aplicación está en etapa beta de escritorio. El README distingue la validación local en macOS Apple Silicon de los paquetes preparados para otras plataformas.

## Tecnologías

React, TypeScript, Vite, Tauri, Rust, SQLite, Next.js.
